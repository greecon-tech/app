# Guides

These are setup and operating guides for people using the Greecon platform day to day, as opposed
to the `docs/` files above them, which describe how the platform is built. Each guide is written
for one kind of site and assumes no prior knowledge of Greecon's own terms.

- `01-farmers.md` — irrigated fields, greenhouses, and other agricultural sites.
- `02-pv-plant-operators.md` — solar (PV) generation sites, including agrivoltaic sites.
- `03-hotels-wastewater.md` — hotels and resorts running their own wastewater treatment plant.
- `04-general-resource-management.md` — any other site managing water, energy, or another natural
  resource that doesn't fit the three above (a municipal pump station, a food-processing plant's
  utilities, a campus energy system, and similar).

All four guides share the same underlying steps — create a site, add devices and reading points,
connect the edge hardware, then watch the dashboard and set up alerts — because that's genuinely
how the platform works for every sector it serves. What differs by sector is which readings matter,
which alerts are worth setting up first, and which report an auditor or inspector is likely to ask
for. Where this document says "your Greecon contact," that is whoever at Greecon onboarded your
account — currently Eridon Manuka (eridon.manuka@greecon.earth).

Greecon is pre-seed and currently running its first pilot deployments. Nothing in these guides
describes a feature that doesn't exist in the running platform today; where a capability is still
planned rather than built, the guide says so plainly instead of describing it as already available.
