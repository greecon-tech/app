Everything in this chapter is done at the office, before the site visit, and it makes install day shorter. About 30 minutes in Greecon and about two hours for the box, and more for the first kit's numbers and its desk test: time it, and write it down. {{who:pm}}

### In Greecon

- {{cb}} **Sign in** at `https://app.greecon.earth/login` with **{{ui.greecon_team}}**. You land on **{{ui.today}}**.
- {{cb}} **A new customer:** if they asked through the web page, their request waits under **{{ui.requests_waiting}}** on **{{ui.today}}** (and on **{{ui.requests}}**): press **{{ui.onboard}}**. Otherwise open **{{ui.clients}}** and press **{{ui.onboard_a_client}}** (top right): company name, owner's name, owner's email, then **{{ui.onboard_client}}**. A box appears, **{{ui.client_onboarded}}**: it is the owner's temporary password, shown once. Write it on the handover page or tell it to the owner by phone. Do not send it by email. If a message says someone already has an account with that email, the person is already a customer: add the new site to the customer they already have.
- {{cb}} **Open the customer for setup:** in the customer's row on **{{ui.clients}}** press **{{ui.open_for_setup}}** (on **{{ui.today}}** the same button is **{{ui.open_account}}** for a site that needs a look and **{{ui.continue_setup}}** for a site being set up). You land on the customer's **{{ui.sites}}** page, with a banner saying you are there as Greecon staff, setting it up. Everything you do is recorded under your own name. The setup session lasts four hours: after that, sign in again with **{{ui.greecon_team}}** and press **{{ui.open_for_setup}}** again. What you saved is still there.
- {{cb}} **Make the site:** on **{{ui.sites}}** press **{{ui.add_a_site}}**. In the form (*{{ui.new_site_form}}*) choose **{{ui.what_kind_of_site}}**: **{{kit.template}}**. The page lists what the template will contain. Enter **{{ui.site_name}}** and **{{ui.where_it_is}}**, check **{{ui.currency_of_bills}}** (it starts as ALL) and **{{ui.site_clock}}** (Europe/Tirane), and press **{{ui.create_the_site}}**.
- {{cb}} **Write down that the papers are signed:** you land on the setup page, titled **{{ui.set_up_site}}** and the site's name, which says `0 of N steps done`, and its first step is **{{step:1}}**. With the signed order form and the agreed data terms in front of you, write in the box who signed for the customer and on what date (it cannot be left empty), and press **{{ui.papers_signed}}**. Nothing goes into a customer's building without both papers.
- {{cb}} **Print the install card:** the link **{{ui.install_card_link}}** is at the top of the setup page. It is your list for the visit: what to bring, what each device is set to and its number, how it is wired, the converter's settings, and what the customer's network is asked for. At the bottom are three messages to copy: send the first to the customer's contact two or three days before, and the second to whoever looks after their network. Each is in English with an *{{ui.albanian_draft}}* folded under it, and someone who writes Albanian every day reads the draft before it is sent.
- {{cb}} **Get the install line:** on the same page press **{{ui.add_box}}**. A line appears, beginning `curl -fsSL https://api...` and ending in a code like `GRC-XXXX-XXXX-XXXX`. Copy it with the copy button. It is shown once. The code works once, for seven days. Press **{{ui.i_have_copied_it}}**.

::: stop
**The install line is the box's key.** Anyone with the line can install a box as this site until it is used or has expired. Treat it like a password: not in email or chat, and pasted straight into the box. If it is lost, or the seven days have passed, press **{{ui.replace_box}}** on the same step; it asks you to confirm and shows a new line. The old line then stops working, and the box that uses the new line takes the place of the box now installed.
:::

### The box on your desk

The operating system and the pasted install line are still a terminal job; everything after them is done on the setup page.

- {{cb}} **Install the operating system** on the box: Debian 12, Ubuntu 22.04 or later, or Raspberry Pi OS 64-bit, with the SSH server on, one user with a long password, and the time zone set to Europe/Tirane. The twenty-minute recipe and the BIOS settings are in {{ref:hardware}}, section 4.3.
- {{cb}} **Connect the box** to your office network and open a terminal on it (a keyboard and screen, or SSH).
- {{cb}} **Paste the install line exactly.** It runs in seven numbered steps and tells you each one: checking the box (and that it can reach Greecon and agrees with it about the time), installing Node.js, making the places the software uses, fetching and checking the Greecon software, giving the box its own credential, starting the service, and waiting to hear that Greecon can see the box. It finishes with `Done. Greecon can see this box.`
- {{cb}} **Refresh the setup page.** **{{step:3}}** now says **{{ui.status_done}}**, with the box's name, its version and "Heard from N seconds ago". You did not press anything to make it so: the platform saw the box.
- {{cb}} **Label the box** with the site name and the date, and pack it. The box keeps its credential when it is moved: unplug it, carry it to the site, plug it in, and it reports from the new place without anything being typed again.
- {{cb}} **Pack the rest** of the kit from the shopping list, the tools, the spares kit, the printed pack and the printed install card.

### The numbers and the converter

The kit is made of approved models, and every device has the same number on the cable in every kit. You set them here, at the office; on site you only check the labels and do not change them. The numbers for this kit are in the table under **Numbers, addresses and ranges** and on the install card. Everything on one cable is **9600 baud, 8 data bits, no parity, 1 stop bit**.

- {{cb}} **Set each meter's number on its own display,** one meter at a time (delivered as unit 1, two on one cable would answer over each other). The SDM630 is delivered at 9600 baud: check it. The SDM230 is delivered at a speed that depends on its version (the V1.6 manual says 2400): set it to 9600, on the Baud Rate page. Powering a meter on a bench is mains work: the electrician makes up the office's bench lead, and you never wire mains.
- {{cb}} **Number the two Waveshare modules** with the maker's setting tool and a USB-to-RS-485 adapter, one at a time (each is delivered as address 1, and there is no switch): **3** on the 4 to 20 mA module (Modbus RTU Analog Input 8CH) and **5** on the pump contact module (Modbus RTU IO 8CH). Use the version of the 4 to 20 mA module that reads current, not the one that reads voltage, and leave its inputs in their default 0 to 20 mA mode, on purpose: a 4 to 20 mA transmitter then reads 4000 to 20000 microamps, and a wire that has come off reads 0, below the 4 mA of an empty tank, which Greecon can see and say.
- {{cb}} **Set the converter** in its web page: mode **Modbus TCP to RTU (gateway)** (not transparent, not raw TCP, not Modbus RTU over TCP), 9600 baud, 8 data bits, no parity, 1 stop bit, TCP port 502. Its address on the customer's network is arranged on site: a fixed one is best, and Greecon finds the converter either way.
- {{cb}} **Label every device with its number** and the converter with its settings, and photograph the labels.
- {{cb}} **Test the kit on the desk.** The registers of the two Waveshare modules are from the maker's published tables and have not been tried on real hardware, so the first real kit is rehearsed on a desk before it is trusted ({{ref:manual}}, section 3.11). Anything that differs from this book is reported to Greecon.

::: tip
**If the line stops with `STOP:`** it says what to check and how. If it stopped before step 5, *Giving this box its credential*, fix the cause and run the same line again: the code has not been used yet. From step 5 on, the code is used up, and the same line would stop with "Greecon did not give the software to this box". Then run the line again with no code at the end: `curl -fsSL https://api.greecon.earth/edge/install.sh | sudo bash -s --`. That repairs the box and keeps its credential. If it answers "This box has no code and has not been installed before", the box never got its credential: press **{{ui.replace_box}}** and use the new line. The commonest stops are a box that cannot reach Greecon (no internet, a firewall that blocks outgoing HTTPS on port 443, or a clock so far out that secure connections fail), and a code already used or older than seven days. A clock only minutes out does not stop the install: it prints a warning, and the setup page later says its clock is N minutes fast.
:::

**The first time, rehearse the whole job on a desk** with a laptop standing in for the kit: {{ref:manual}}, section 3.11. It takes an afternoon and finds the mistakes in the room instead of at the customer's.
:::
